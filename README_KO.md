## 이 저장소를 만든 이유

레오가 석사 과정에서 수학적 정의와 프로그램이 정확히 대응하는 장면을 본 곳이 바로
여기입니다. 귀납적으로 정의된 언어, 절 단위로 정의된 의미론, 그리고 그것을 한 줄씩
옮긴 코드.

원래 과제는 결과만큼 코드로도 평가되었고 구술 시험까지 있었습니다. 과제지는 이렇게
강조했습니다. *"Make sure that your code is clear and well commented. The quality of
your code will be taken into account."* 논리학뿐 아니라 프로그램 설계에 대해 그가 가장
많이 배운 과제였고, 그래서 우리는 이것을 테스트 묶음을 앞세워 다시 쌓기로 했습니다.

이 사슬은 끝에서 끝까지 이어집니다. 프랑스어 문장이 들어가고, 진리값이 나옵니다.

## 각 단계에서 알아낸 것

**1. 명제 논리: 구문, 의미, 모델 검사**  
이 솔버는 *거짓*이라고 답하지 않고 반례를 제시합니다. 땅은 젖었는데 비는 오지 않았다. 스프링클러입니다.

**2. 모델 만들기: 정규형과 DPLL**  
함의의 사슬에서 DPLL은 결정을 한 번도 하지 않고 ×315의 이득을 냅니다. 비둘기집 원리에서는 벽에 부딪히는데, 1985년 Haken이 다항 크기의 분해 증명이 존재하지 않음을 증명했습니다.

## 우리의 작업 원칙

**내려받을 것이 없습니다.** 말뭉치는 코드 안에 직접 써 넣었습니다. 레오가
석사 과정에서 쓴 노트북은 모두 대학 서버로 `wget`을 보내거나 Google Drive를
마운트하는 줄로 시작했고, 두 해가 지난 지금 그 절반은 더 이상 실행되지 않습니다.

**측정하지 않은 것은 주장하지 않습니다.** 이 문서의 모든 수치에는 다시 실행해 볼 수
있는 명령이 하나씩 대응합니다.

**원래 과제의 오류는 지우지 않고 인용합니다.** 제출했던 결과가 틀렸거나 불완전했던
경우에는 그렇다고 밝히고 올바른 값을 함께 적습니다.

**부정적인 결과도 그대로 둡니다.** 기대와 반대되는 결과가 나왔을 때는 실제로 관찰한
것을 기록합니다.

**코드 주석은 프랑스어입니다.** 레오가 그 언어로 생각하며 쓴 코드이기 때문입니다.
문서는 영어로 쓰고, 해을이 따라잡은 부분은 한국어로도 씁니다.
